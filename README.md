# Panorama

An interactive 360° panorama viewer for the web.

## 🔗 Preview

**Live demo:** [https://vi-kush.github.io/panorama/](https://vi-kush.github.io/panorama/)

Drag to look around, scroll or pinch to zoom.

## Run locally

Clone the repo and serve it with any static server (opening `index.html` directly with `file://` may block the images from loading):

```bash
git clone https://github.com/vi-kush/Panorama.git
cd Panorama
npx serve .
```

Then open the URL shown in the terminal.

## Deployment

The site is deployed automatically to GitHub Pages via GitHub Actions on every push to `main`.
